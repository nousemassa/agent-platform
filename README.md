# Платформа: шесть сервисов как сабмодули

**Что это.** Воркспейс, из которого поднимается вся система: поиск, модели, два продукта, общий слой и
рабочая обвязка. Каждый сервис — отдельный репозиторий, подключённый сабмодулем.

| Каталог | Репозиторий | Что это |
|---|---|---|
| `agent-core/` | `agent-core` | общий слой: настройки, базы, каналы, телеметрия, лексика решений |
| `infra/` | `infra` | рабочая обвязка: юниты, сторожа, дампы, подъём стенда |
| `realty/` | `realty` | продукт: диалог, брони, объявления, напоминания |
| `news/` | `news` | продукт: бот канала новостей и выпуск |
| `models/` | `models` | модели и GPU: эмбеддинги и решатель |
| `search/` | `search` | поиск: инстанс SearXNG и MCP-обёртка |

## Как поднять

```bash
git clone --recurse-submodules git@github.com:nousemassa/agent-platform.git
cd agent-platform
bash infra/bootstrap.sh --check     # предпосылки и раскладка, ничего не пишет
bash infra/bootstrap.sh             # вендор → модели → поиск → продукты → обвязка
```

Дальше — заполнить секреты развёртывания в `.env` (образец: `infra/templates/workspace/.env.example`):
доступ к платформе, Telegram, ключи LLM. Порядок шагов и что именно остаётся руками — в
`infra/bootstrap.sh` и в отчёте `REVIEW-bootstrap.md` (лежит в обвязке).

## Как обновлять

Пин сабмодуля двигается отдельным коммитом: в проекте — коммит и push, здесь —
`git submodule update --remote <каталог>` и коммит «Поднять <каталог> до <sha>». Так видно, что именно
изменилось в платформе.
